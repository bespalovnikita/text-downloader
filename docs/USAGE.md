# Работа с Text Downloader

## Установка и первый запуск

1. Скачайте `TextDownloader-Windows-x64.zip` из последнего стабильного выпуска.
   Рядом можно скачать `SHA256SUMS.txt` и сверить SHA-256 архива.
   [Официальные выпуски](https://github.com/bespalovnikita/text-downloader/releases)
2. Распакуйте ZIP целиком в папку, доступную для записи. Оставьте все файлы
   комплекта рядом с `TextDownloader.exe` и запустите его.
3. Вставьте адрес рассказа или публикации, нажмите **«+ Добавить»** и выберите
   папку назначения и формат. По умолчанию книги сохраняются в папке
   `TextDownloader` внутри ваших «Документов».
4. Нажмите **«Скачать очередь»**. После завершения выберите задание и нажмите
   **«Открыть книгу»** или **«Показать в папке»**.

Приложение работает в Windows 10/11 x64. В архив уже включена среда выполнения .NET.

## Очередь и предпросмотр

- В верхнее поле можно вставить несколько ссылок. **«Вставить»** сразу
  добавляет ссылки из буфера. **«Открыть список…»** загружает адреса из
  текстового файла. Ссылки и файлы `.txt` также можно перетащить в окно.
- Слева находится очередь, в центре показаны прогресс, ошибки и журнал,
  справа — название и начало выбранного рассказа. Разделителями можно менять
  ширину панелей. **«Обновить сведения»** заново запрашивает предпросмотр.
- Выберите строку в **«Очереди»** или **«Загрузках»** и нажмите
  **«Копировать ссылку»** в этой панели. В буфер попадёт адрес рассказа или
  публикации, сохранённый в выбранном задании.
- **«Удалить выбранные»** убирает строки очереди, **«Убрать готовые»**
  убирает завершённые. Сохранённые книги остаются на диске и в истории.
- **«Повторить выбранные»** ставит выбранные задания обратно в очередь.
  Повторный экспорт подбирает свободное имя файла.
- Флажок **«Сворачивать в трей»** отправляет окно при сворачивании в область
  уведомлений Windows. Окно можно открыть со значка в трее.

Через командную строку можно передать адрес или путь к списку. Это добавляет
задания в очередь для последующего запуска в окне.

```powershell
.\TextDownloader.exe "https://sefan.ru/stories/ru/2/g/chitat_irina-chast-32_1.html"
.\TextDownloader.exe "C:\Books\stories.txt"
```

## Рассказы и циклы Sefan

Добавьте страницу чтения вида `название_1.html` или `название_1-2.html`.
Программа начнёт с первой страницы указанной части. Поддерживаются разные
стили отображения и жанры, префикс `chitat_` в имени необязателен. Если сайт
показывает предупреждение 18+, совершеннолетний читатель может поставить
флажок подтверждения в настройках задания.

Если на странице есть **«Оглавление»**, программа возьмёт список частей рядом
с этой ссылкой или прочитает отдельную страницу оглавления. В книгу попадут
все перечисленные части, включая предыдущие и последующие, если они указаны.
Например, по ссылке на третью часть «Ирины» будут собраны части 1, 2 и 3.
[Страница из примера](https://sefan.ru/stories/ru/2/g/chitat_irina-chast-32_1.html)

Каждая часть становится главой. Внутри главы страницы соединяются с
сохранением абзацев и слов, разбитых на границе страниц. У самостоятельного
рассказа без оглавления весь текст остаётся одной главой. Каталоги, поиск,
страницы анонсов и страницы автора сами по себе не добавляются в очередь.

## Циклы Bestweapon

Добавьте ссылку вида `https://bestweapon.cc/post_124145`. Загрузчик читает
оглавление цикла на сайте и собирает предыдущие части до выбранной включительно:
в этом примере — части 1–8, в правильном порядке. Для ссылки
`https://bestweapon.cc/post_123186` будут собраны части 1–7.

Предпросмотр загружает только выбранную публикацию. Полная загрузка проверяет
состав цикла и создаёт одну книгу: оглавление в начале EPUB, отдельные главы
и переходы к ним; в FB2 — разделы с заголовками для оглавления читалки.
Рекомендации и посторонние публикации на странице не входят в книгу.
Картинки и комментарии не экспортируются.

Если цикл не удаётся подтвердить полностью, готовая книга не публикуется.

## Задержка между запросами

Введите число в поле **«Задержка между запросами, с»**. По умолчанию стоит
одна секунда. Минимум — `0,1` секунды. Можно вводить десятичную запятую
или точку, например `0.5`. Значение сохраняется в профиле.
Пока поле содержит недопустимое значение, запуск очереди недоступен.

Действует для сетевых запросов к каждому сайту, включая предпросмотр.
Страницы из кеша читаются без ожидания. Временные ошибки HTTP могут добавить
свою паузу перед следующей попыткой.

## Пауза и продолжение после ошибки

После проверки страница записывается в кеш. Если из 100 страниц успешно
сохранены 20, повтор запрашивает страницу 21. Если оборвалась запись страницы
20, повтор запрашивает страницу 20. Для циклов сохраняются и страницы уже
пройденных глав. Очередь восстанавливается при запуске приложения и ждёт команды.

- После **«Пауза»** нажмите **«Продолжить очередь»**. Пауза прерывает
  текущий запрос и останавливает очередь до следующего запуска.
- После ошибки или **«Отменить загрузку»** нажмите **«Повторить ошибки»**,
  затем **«Скачать очередь»**. Готовые файлы сохраняются.
- При сбое запроса панель **«Продолжение после ошибки»** показывает причину,
  адрес последней успешной страницы и адрес для продолжения. Нажмите
  **«Копировать»** рядом с последней успешной страницей, чтобы открыть её
  в браузере и найти адрес страницы, на которой произошёл сбой.
  Вставьте этот адрес в поле **«Адрес страницы для продолжения»**,
  нажмите **«Принять адрес»**, затем **«Скачать очередь»**. Приложение сверяет
  рассказ, часть и номер страницы перед повтором. Если последней успешной
  страницы ещё нет, доступен адрес первого сбойного запроса.
- Чтобы намеренно перечитать текст с сайта, включите
  **«Скачать заново (без кеша)»**, выберите задание, нажмите
  **«Повторить выбранные»**, затем запустите очередь. У новой загрузки своя
  папка кеша. Если она прервётся, обычный повтор ошибок продолжит эту же
  загрузку, даже когда флажок остаётся включённым.

При сообщении Sefan «Ссылка ведёт на другой рассказ» программа один раз
пробует маршрут с жанром `i`, сохраняя имя, язык и часть. Например,
`/stories/ru/2/drama/название_1.html` → `/stories/ru/2/i/название_1.html`.
У маршрутов отдельный кеш. Если попытка на маршруте `i` прервётся, повтор
использует её точку продолжения. Предпросмотр также поддерживает маршрут `i`.

Изменившееся число страниц, пропуск, повтор текста или недоступная часть
останавливают сборку, если полноту подтвердить не удаётся. Причину можно
посмотреть в панели ошибки и в разделе **«Журнал»**. Кнопка
**«Сохранить журнал…»** записывает журнал в текстовый файл.

## История и данные

Настройки, очередь и история находятся в `%LOCALAPPDATA%\TextDownloader\session.json`.
Откройте **«История…»**, чтобы увидеть название, источник, дату и пути
опубликованных книг. Если файл перенесён вручную, история хранит исходный путь.
Проверенные страницы хранятся в подкаталоге `cache`. Удаление кеша после
закрытия приложения освобождает место, но следующая загрузка начнётся заново.

Повреждённое сохранение не перезаписывается автоматически. Сохраните его копию
перед ручным восстановлением. Для резервной копии профиля закройте приложение
и скопируйте каталог `%LOCALAPPDATA%\TextDownloader`.

У приложения собственный профиль. Настройки Video Downloader не импортируются.

## Обновления

Откройте **«Обновления…»**. В окне показаны текущая и доступная версии;
сведения берутся из официальных стабильных релизов `bespalovnikita/text-downloader`.
Кнопка **«Проверить»** повторяет запрос, если сервер временно недоступен.

При наличии новой версии нажмите **«Обновить и перезапустить»**. Программа скачает
ZIP с отображением прогресса, сверит SHA-256, содержимое пакета и версию EXE.
До передачи установки можно отменить загрузку или закрыть окно обновления.
Если выполняется скачивание рассказа, установка ждёт его завершения; можно
закрыть окно обновлений и поставить очередь на паузу.

После подготовки программа сохраняет очередь и настройки и закрывается.
Временная копия установщика ждёт завершения процесса, заменяет только файлы
поставки и запускает новую версию. Профиль в `%LOCALAPPDATA%\TextDownloader`,
кеш, история, скачанные книги и посторонние файлы сохраняются.
Восстановленная очередь не начинает скачивание автоматически.

Сохраните `windows-package.json` рядом с EXE: он определяет файлы установленного
комплекта. Если пакет повреждён, изменён, распакован не полностью или папка
недоступна для записи, приложение сообщает об этом до установки.
При ошибке замены выполняется откат. После аварийного прерывания следующий запуск
сначала восстанавливает предыдущую версию; резервные файлы хранятся в
`%TEMP%\TextDownloaderUpdates`. Если восстановление невозможно, программа оставит
их на месте и сообщит об ошибке. Сохраните резервные копии и собственные изменённые
файлы перед ручным восстановлением.

**Для первого перехода с `v0.1.2` и более ранних версий** распакуйте полный новый ZIP
в новую папку и запустите EXE. После этого следующие обновления устанавливаются
кнопкой в приложении. Намеренный переход к старой версии также выполняется вручную.

## Форматы

EPUB 3 включает метаданные, титульную страницу, ссылку на источник,
современное оглавление и NCX для старых читалок. FB2 использует пространство имён
FictionBook 2.0. Текст проверяется на корректность XML и точное сохранение абзацев.
Для каждого выбранного формата создаётся один файл книги со всеми главами.
У цикла каждая часть получает собственный заголовок и ссылку на источник.
При выборе **«EPUB + FB2»** в папке появятся два файла одной книги.
В книгу входят текст и абзацы. Иллюстрации, комментарии и оформление сайта
остаются на исходных страницах.
