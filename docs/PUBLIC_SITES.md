## Сетевые проверки

GitHub Actions выбирает случайное произведение для каждого сайта, скачивает доступную главу без входа и сверяет её текст после экспорта в FB2.

Запуск проверки одной партии из корня репозитория

```sh
dotnet run --project tests/TextDownloader.Core.Tests -c Release -- --live-public-sites --batch 10
```
