# Text Downloader

Windows-приложение для скачивания рассказов, ранобэ и фанфиков
с сохранением в **EPUB, FB2 или оба формата**. Интерфейс и устройство Windows-клиента
основаны на [Video Downloader](https://github.com/bespalovnikita/video-downloader).

## Скачать и запустить

1. Откройте [Releases](https://github.com/bespalovnikita/text-downloader/releases).
2. Скачайте `TextDownloader-Windows-x64.zip` и распакуйте архив целиком.
3. Запустите `TextDownloader.exe`.

Поддерживаются **Windows 10/11 x64**. Устанавливать .NET, Python или PowerShell
для работы приложения не нужно. PowerShell и .NET SDK нужны только разработчику.
Рядом с ZIP публикуется `SHA256SUMS.txt` для проверки целостности.

## Скачать рассказ

1. Вставьте ссылку на страницу чтения и нажмите **«Добавить»**.
2. Выберите формат, папку результата и задержку между запросами от 0,1 секунды.
3. Если сайт запросил подтверждение возраста, совершеннолетний читатель может
   включить подтверждение 18+ в приложении.
4. Нажмите **«Скачать очередь»**.
5. Откройте готовую книгу или папку результата из приложения.

Например, ссылка вида:

```text
https://sefan.ru/stories/ru/2/drama/chitat_na-drugom-beregu_1.html
```

Можно вставить и вторую страницу `…_1-2.html`: загрузчик начнёт рассказ с первой.
Поддерживаются нумерованные страницы чтения `название_N.html`
и `название_N-2.html`. Префикс `chitat_` не обязателен: имя рассказа может начинаться иначе.
Жанр не ограничен. При ошибке «Ссылка ведёт на другой рассказ» программа один раз
повторяет предпросмотр или загрузку с первой страницы, заменив жанр в адресе на `i`.
Имя рассказа и часть сохраняются; порядок и полнота страниц проверяются заново.
Если у рассказа есть оглавление, программа собирает все перечисленные части
в одну книгу. Ссылка на третью часть «Ирины» даёт книгу из частей 1–3.
[Страница из примера](https://sefan.ru/stories/ru/2/g/chitat_irina-chast-32_1.html)

Для Bestweapon вставьте ссылку на публикацию, например:

```text
https://bestweapon.cc/post_124145
```

Программа использует оглавление цикла на сайте и собирает все предыдущие части
до указанной включительно. Для этого примера результат содержит части **1–8**.
Каждая часть становится отдельной главой с собственным пунктом оглавления EPUB
и заголовком раздела FB2. Ссылка на 7-ю часть даёт книгу из частей 1–7.
Предпросмотр показывает выбранную публикацию; весь цикл загружается по команде
**«Скачать очередь»**.

## Возможности

- Очередь ссылок, вставка из буфера и перетаскивание ссылок в окно.
- Единая очередь с прогрессом и статусами, предпросмотр выбранного произведения.
- Последовательный обход настоящих ссылок «Далее» и проверка полноты рассказа.
- Прогресс, пауза, отмена и продолжение с первой незагруженной страницы.
- Адрес последней успешной страницы можно скопировать. Для сбойной страницы
  можно указать другой адрес в панели восстановления.
- Корректная склейка страниц, которые обрываются посреди предложения или слова.
- EPUB с титульной страницей и оглавлением, FB2 с метаданными и заголовками частей.
- Циклы Sefan и Bestweapon с отдельной главой на каждую часть.
- История успешно сохранённых книг, открытие книги или её папки.
- Сохранение очереди и настроек, восстановление после перезапуска без автозапуска загрузки.
- Журнал, сворачивание в системный трей и установка обновлений с перезапуском приложения.

## Поддержка и ограничения

- Поддерживаются раздел рассказов **Sefan.ru** и публикации **Bestweapon.cc**.
- Для открытых ранобэ и фанфиков можно вставить ссылку на произведение или главу.
  Приложение начинает загрузку с первой главы. Поддерживаются FanFiction.Net,
  FictionPress, Fanfics.me, Ranobe.me, Scribble Hub, Shōsetsuka ni Narō,
  Kakuyomu, Fimfiction, ReadNovel, ReadNovelFull, Hiraeth Translation,
  Fantasy World Online, NovelFull, FreeWebNovel, WoopRead, 爱下电子书,
  NovelRare, Divine Dao Library, NoBadNovel, Lazy Girl Translations, Jobnib,
  Snowy Codex, TeaNovel, Novel Mania, Dobytranslations, Asura Scans,
  NovelFrance, MegaNovel, Light Novel Translations, Revenger Novels,
  Dusk Blossoms, Virlyce, IndoWebNovel, Chereads, Second Life Translations,
  LabNovel, MyDramaNovel, Psychfic, Portkey Archive и Stories of Arda.
- На Sefan состав цикла берётся из оглавления. Каталоги, поиск и страницы
  анонсов `_nova.html` не обрабатываются.
- На Bestweapon состав и порядок цикла определяются по оглавлению публикации.
  Недоступная часть, пропуск номера или противоречивые ссылки останавливают сборку.
  Публикации после выбранной части автоматически не добавляются.
- Экспортируется текст с абзацами. Иллюстрации и оформление HTML не переносятся.
- При невозможности подтвердить последнюю страницу загрузка завершается ошибкой.
  Уже полученные страницы сохраняются в кеше для повторной попытки.
- Пауза отменяет текущий запрос; при продолжении недокачанная страница запрашивается заново.
- В окне **«Обновления…»** можно проверить версию и нажать **«Обновить и перезапустить»**.
  Программа проверяет официальный ZIP, сохраняет очередь и настройки, закрывается,
  устанавливает обновление и запускается снова. При сбое предусмотрены откат и восстановление.
  Для проверки обновлений официальный репозиторий должен быть публично доступен.
- Первый переход с `v0.1.2` и более ранних версий выполняется через распаковку полного ZIP:
  прежние версии умеют скачивать архив, но ещё не устанавливают его автоматически.
- Изменение разметки сайта может потребовать обновления адаптера.

Скачанные рассказы и пользовательские данные не входят в репозиторий.
Сведения о лицензиях библиотек находятся в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
